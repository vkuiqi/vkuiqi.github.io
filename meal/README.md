# 减脂餐

每天两顿正餐。晚上一次做两份，一份当晚吃，一份装盒第二天中午带走。早餐固定两个水煮蛋加一盒牛奶，早上不做饭。

## 目标

| 项目 | 数值 |
|---|---|
| 身高 / 起始体重 | 170 cm / 74 kg（148 斤） |
| 目标体重 | 130 斤 |
| 每日摄入 | 1800 kcal，可接受区间 1650–1950 |
| 判断依据 | 看七天平均，不看单日 |
| 周预算 | 12600 kcal |
| 蛋白质 | 每天不低于 110 g，一周至少五天达标 |

## 一餐怎么配

一道荤菜（一掌半蛋白，约 200 g 生重）＋ 一道素菜（两捧，300–400 g）＋ 生米 70 g ＋ 一个水果，约 760 kcal，油一顿控制在 10 g 以内。

## 两条不动的原则

吃不够蛋白的减脂餐等于白减，掉的是肌肉。热量可以浮动，蛋白不能欠。

能做半年的是饭，不是方案。蒸鸡胸撑不过两周，家常菜少半碗饭能一直吃。
