# 公积金测试

石家庄住房公积金项目（贝贝 2.0）的测试资料。这块是常驻的，踩过的坑和查得到的东西都往这儿放，省得下次再翻聊天记录。

## 工具

- [测试数据台](/hp/tool/ ':ignore') — 生成符合业务规则的缴存人、缴存单位、提取、贷款测试数据，含编号校验、脱敏、Schema 导入

测试数据台是单文件离线应用，数据不出本机，整页打开。

| 互联互通 | 转移接续、异地业务 |

## 常用口径

- 机构编号：`1301010005`（石家庄）
- 表命名规律：`PT_DXSL_<机构>_<模块>`，常用视图 `v_pt_dxsl_*_gc`
- 缴存基数上下限：占位值 2200 ~ 26562，实际以中心当年公布值为准
- 灵活就业人员补缴：`JCRYLX IN ('2','4')` 且连续缴存月数 ≥ 6，应缴年月早于当年
- 定时任务：`FM-银行流水定时更新`，cpcwzj 应用，cron `0 0 1/1 * * ?`
